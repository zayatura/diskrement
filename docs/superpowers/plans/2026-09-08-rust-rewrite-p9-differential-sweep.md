# Rust Rewrite P9 — the randomized differential sweep Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land P9 — a `proptest`-driven command-sequence generator inside
`diskrement-difftest` that runs generated sequences through all three modes
step by step, reports the *exact diverging step* as paste-ready corpus source,
and then a wide run whose every counterexample is fixed and promoted to a named
scenario.

**Architecture:** The harness today runs a whole scenario and diffs the end
state. P9 splits that into reusable halves — a `Session` (scratch tree plus
environment, one step at a time) and a `StateSnapshot` (the end-state capture,
now takeable mid-run) — with `runner::run` kept as a fold over the new pieces so
the eight phases of existing scenarios prove the refactor. On top of that sits
`sequence`: a `Model` of the project lifecycle that turns opaque generated bytes
into legal-biased command sequences, and a `Sweep` value whose `Debug` prints
the sequence as `corpus.rs` source. The sweep test holds three worlds open at
once — all-Scala as the reference, all-Rust, and interleaved — applies each
generated step to all three, and diffs after every command.

**Tech Stack:** Rust 2021; `proptest` 1 (already a dev-dependency of
`diskrement-difftest`, so far unused), `serde_json`, `rusqlite` (bundled),
`sha2`, `tempfile`. **No new dependency and no manifest change** — see *Design
decisions*, D5.

**Spec:** `docs/superpowers/specs/2026-09-05-rust-rewrite-design.md` — §3.1 (the
compatibility claim the interleaved mode tests), §3.2 (the argument-parser
wording exemption, which the generator deliberately stays out of), §7 (a skip
must state its reason and its count), §8.1 (the `sequence` bullet and the four
decisions recorded there when this plan was written), §9 (the P9 row:
*"Randomized differential sweep: the `proptest` command-sequence state machine,
run wide once and narrow thereafter"*, ending with *"Generated sequences agree
across all three modes; every shrunk counterexample is either fixed or promoted
to a named scenario"*).

## The lifecycle the model encodes

Read from `crates/diskrement-shell/src/pipeline/mod.rs` — these are the
transitions the generator steers by, verified against the source rather than
assumed:

| command | precondition | effect on staged state |
|---|---|---|
| `init p --source S --work-dir W` | the project does not exist | creates it |
| `scan p` | the project exists | writes `staged/scan.json`; creates `work/snapshot` |
| `plan p [--finalize] [--disc-type T]` | a staged scan (`mod.rs:196`) | writes `staged/plan.json`; **does not consume the scan**, so re-planning is idempotent |
| `burn p --yes` | a staged scan *and* a staged plan (`mod.rs:231`) and `work/snapshot` (`mod.rs:263`) | on success: appends one disc/session, then `staged::clear` and `snapshot::release` (`mod.rs:330-332`) — so scan, plan and snapshot are all gone |
| `verify p [--disc N]` | the project exists | none |
| `history p PATH` | the project exists | none |
| `reset p` | the project exists | `staged::clear`, removes `burn-catalog.sqlite`, the staging trees and the snapshot (`mod.rs:521`) |
| `disc mark-dead p N --yes` | the project exists and disc `N` exists and is not already dead | appends a `disc_event` |

One transition is worth the generator's existence on its own: `plan`, then
`disc mark-dead` on the ordinal that plan targeted, then `burn` is
`PipelineError::StalePlan` (`mod.rs:252-260`) — a three-command interleaving
that no hand-written corpus scenario reaches, and whose advice string is pinned
by `ExitMappingSpec` on the Scala side.

## Design decisions taken in this plan

**D1 — The model steers; it is not the oracle.** `Model`'s transition table is
a *distribution shaper*, not an assertion. If it calls a command legal that
isn't, both binaries reject it identically and the case still passes. This is
what lets the model stay a hundred lines instead of being a second
implementation of the pipeline, and it must be stated in the module doc so
nobody later "fixes" the model by making it exact.

**The one exception, and it is load-bearing:** `Op::Delete` is executed by
`std::fs::remove_file`, which *errors* on a missing file and aborts the case
with a `Skip`. So `Model` must be exactly right about which files are present.
Task 4 pins that as a property test rather than a comment.

**D2 — Opaque selectors, not state-dependent generation.** Plain `proptest`
strategies cannot consult state mid-sequence. So `proptest` produces
`Vec<(u8, u8, u8)>` and `Model::interpret` turns each triple into an `Op`
against the state built by everything before it. `Vec` shrinking removes steps;
`u8` shrinking pulls each triple toward `(0, 0, 0)`, which by construction means
*legal*, *the first op in the legal list*, and *the smallest payload*. A shrunk
value is re-interpreted rather than replayed, which is sound because proptest
requires only that the shrunk case still fail.

The three bytes are `(selector, chooser, payload)`: the selector decides legal
versus illegal, the chooser indexes the resulting list, and the payload picks a
file size. Three bytes rather than two because otherwise the chooser would have
to carry both the op choice and its size, and the write ops would swamp the
command ops in the list.

**D3 — The counterexample is paste-ready source.** `Sweep`'s `Debug` prints the
interpreted ops in `corpus.rs` syntax. proptest prints `Debug` of the shrunk
input on failure, so the failure output *is* the body of the named scenario the
counterexample gets promoted to. This is what makes §9's "either fixed or
promoted" bar cheap enough to actually hold to.

**D4 — Comparison is step-wise, over three simultaneous worlds.** `runner::run`
splits into a `Session` and a per-step `apply`, and the sweep holds three
`Session`s open at once. A counterexample then names the diverging step instead
of only the sequence that ends wrong, and shrinking has less work to do.

Two consequences to keep in mind while implementing:

- Each world needs **its own `Normalizer`**, because instant ordinals are
  assigned in first-appearance order and the three worlds live in three
  different scratch roots. All three must be advanced at the same points, in the
  same order, or their ordinal numbering stops corresponding.
- `state_snapshot` opens SQLite with `immutable=1`, which reads only the main
  database file and ignores any `-wal`. That is safe **only because snapshots
  are taken between command invocations**, with no binary running: SQLite
  checkpoints and removes the `-wal` when the last connection closes. Never call
  `state_snapshot` while a child process is alive.

**D5 — `sequence` stays free of `proptest`.** `Model`, `Op` and `Sweep` are
plain values in `src/sequence.rs`; the three-line `Strategy` that produces a
`Sweep` lives in `tests/sweep.rs`. So `proptest` stays a *dev*-dependency, the
manifest is untouched, and the whole generator is unit-testable by ordinary
`cargo test` with no proptest machinery involved.

**D6 — The generator stays out of the argument parser.** §3.2 sanctions clap and
zio-cli wording argument errors differently, and the corpus already covers that
surface with `Expect::ExitOnly` steps. So no generated op produces a bogus
`--disc-type`, a non-numeric `--disc`, an ordinal of `0`, or a missing required
argument. Every generated step is `Expect::Full`, which means every generated
step's *stdout* is compared — which is the point.

**D7 — The generator never drives the real backend.** No `cmd_real`, so
`Scenario::required_tools()` is empty for every generated scenario and the sweep
needs no `xorriso`.

**D8 — Failure persistence is off.** proptest would otherwise write
`.proptest-regressions` into a crate P10 deletes. The promotion path is
`corpus::all()` — a reviewed, committed, JVM-free-until-run artifact — not a
seed file.

```rust
/// Capture one command's outcome.
pub fn step_snapshot(step: &StepOutcome, norm: &mut Normalizer) -> StepSnapshot {
    StepSnapshot {
        label: step.label.clone(),
        exit: step.exit,
        stdout: match step.expect {
            Expect::Full => Some(norm.text(&step.stdout)),
            Expect::ExitOnly => None,
        },
    }

/// Capture everything currently on disk in `scratch`.
///
/// **Only call this with no child process running.** It opens SQLite with
/// `immutable=1`, which reads the main database file and ignores any `-wal`;
/// that is complete only once the writing process has exited and SQLite has
/// checkpointed. Between two command invocations, which is where the sweep
/// calls it, that always holds. SQLite drops the `-wal` when the last
/// connection closes, so a cleanly exited child leaves a complete main file; a
/// killed one does not. Violating this is silent — you read a stale database
/// and report a difference that is not there, or miss one that is.
///
/// Takes the run's own `Normalizer` so that instant ordinals stay consistent
/// across every value the run produces.
```

```rust
/// One scratch tree, its environment, and the ability to apply steps to it one
/// at a time.
///
/// `run` folds a whole scenario over this; the sweep holds three of them open
/// at once and diffs between steps. The counters live here rather than in the
/// caller because both of them — the write index that pins mtimes and the
/// command index that drives the alternation — must advance exactly once per
/// applicable step, and a caller that forgot one would produce a difference
/// that looks like a porting bug.
pub struct Session<'a> {
    bins: &'a Binaries,
    mode: Mode,
    disc_bytes: Option<u64>,
    scratch: Scratch,
    write_index: u32,
    command_index: usize,
}

impl<'a> Session<'a> {
    /// Create the scratch tree. `Skip` when this machine cannot host one.
    ///
    /// A `mode` that needs the Rust binary requires `preflight` to have passed
    /// first: `invoke` panics rather than checking again per step.
    pub fn open(bins: &'a Binaries, mode: Mode, disc_bytes: Option<u64>) -> Result<Self, Skip> {
        Ok(Session {
            bins,
            mode,
            disc_bytes,
            scratch: scratch()?,
            write_index: 0,
            command_index: 0,
        })
    }

    /// Borrow the scratch tree mid-run, for a snapshot taken between commands.
    /// Use `into_scratch` at the end, when the tree must outlive the session.
    pub fn scratch(&self) -> &Scratch {
        &self.scratch
    }

    /// The mode every command step runs under, so a caller can label a report
    /// without keeping a second copy.
    pub fn mode(&self) -> Mode {
        self.mode
    }

    /// How many command steps have been applied. `Mode::which` takes this.
    pub fn command_index(&self) -> usize {
        self.command_index
    }

    /// Give up the scratch tree, keeping it alive in the caller.
    pub fn into_scratch(self) -> Scratch {
        self.scratch
    }

    /// Apply one step. `Ok(None)` for a tree mutation, which runs no binary.
    ///
    /// Advances the command index for command steps only, so a file write
    /// between two commands never shifts the alternation. The binary is chosen
    /// from this session's mode and the count of commands *before* this one.
    pub fn apply(&mut self, step: &Step) -> Result<Option<StepOutcome>, Skip> {
        match step {
            Step::Write { rel_path, version, size } => {
                let path = self.scratch.source.join(rel_path);
                if let Some(parent) = path.parent() {
                    std::fs::create_dir_all(parent)
                        .map_err(|e| Skip(format!("creating {}: {e}", parent.display())))?;
                }
                std::fs::write(&path, content(rel_path, *version, *size))
                    .map_err(|e| Skip(format!("writing {}: {e}", path.display())))?;
                pin_mtime(&path, SOURCE_MTIME_BASE_MILLIS + u64::from(self.write_index))?;
                self.write_index += 1;
                Ok(None)
            }
            Step::Delete { rel_path } => {
                let path = self.scratch.source.join(rel_path);
                std::fs::remove_file(&path)
                    .map_err(|e| Skip(format!("deleting {}: {e}", path.display())))?;
                Ok(None)
            }
            Step::Cmd { label, args, expect, backend } => {
                // Read before the increment: the binary for a command is
                // chosen by the count of commands *before* it, so deriving
                // `which` afterwards would still alternate but start the
                // interleave with Scala — and stop exercising the Rust→Scala
                // direction, the one the frozen corpus cannot reach.
                let which = self.mode.which(self.command_index);
                self.command_index += 1;
                Ok(Some(self.invoke(label, args, *expect, backend, which)?))
            }
        }
    }

    /// Spawn one binary. The whole body is the existing `Step::Cmd` arm of
```

```rust
///
/// Returns `Skip` — never a panic — when the environment cannot support the
/// run, so the caller can report it as a skip with its reason.
pub fn run(bins: &Binaries, scenario: &Scenario, mode: Mode) -> Result<RunOutcome, Skip> {

        }
    }

        mode,
        steps,
        scratch: session.into_scratch(),
    })
}
```

```rust
//! Generated command sequences: the pool, the lifecycle model, and the value a
//! `proptest` strategy produces (spec §8.1, the `sequence` bullet).
//!
//! **The model steers; it is not the oracle.** Its transition table shapes the
//! distribution of generated sequences so that they reach burns, spills,
//! supersessions and coasters instead of dying on the first error. It is *not*
//! an assertion about the pipeline: if it calls a command legal that is not,
//! both binaries reject it identically and the case still passes. That is what
//! keeps it a hundred lines rather than a second implementation of
//! `pipeline::mod`, and it is why nobody should later "fix" it by making it
//! exact.
//!
//! The one exception is `Op::Delete`, which `Session::apply` performs with
//! `fs::remove_file` — that errors on a missing path and aborts the case. So
//! `live` must be exactly right, and a test pins it against a shadow of the
//! filesystem.
//!
//! Deliberately absent: anything that fails in the argument parser. Spec §3.2
//! lets clap and zio-cli word those differently, and the corpus covers them
//! with `Expect::ExitOnly` steps. Every generated step is `Expect::Full`, so
//! every generated step's stdout is compared.
//!
//! No `proptest` here: this module is plain values, unit-testable by ordinary
//! `cargo test`. The strategy that produces a `Sweep` lives in `tests/sweep.rs`.

use std::collections::{BTreeMap, BTreeSet};

use crate::runner::PROJECT;

/// The source-file names a generated sequence may touch.
///
/// A fixed pool rather than generated strings: every name has to be a legal
/// relative path everywhere the harness runs, and the interesting variation is
/// depth, not spelling. Four names is enough to spill a 1000-byte disc,
/// supersede a version and leave a tombstone while keeping the model small.
pub const FILES: &[&str] = &["a.bin", "b.bin", "nested/c.bin", "deep/x/d.bin"];

/// Payload sizes. `3000` exceeds the smallest generated capacity on its own, so
/// the oversize path — `plan` lists it and succeeds, `burn` refuses with exit
/// 3 — is reachable by generation rather than only by hand.
pub const SIZES: &[usize] = &[120, 400, 800, 3000];

/// `DISKREMENT_DISC_BYTES` values, most constrained first.
///
/// Order matters: `prop::sample::select` shrinks toward the first element, and
/// a counterexample that still reproduces on a 1000-byte disc is the more
/// useful artifact — it is the one that spills, seals and fills.
pub const DISC_BYTES: &[Option<u64>] = &[Some(1000), Some(4000), None];

/// A project name no generated `init` ever creates.
pub const UNKNOWN_PROJECT: &str = "nosuch";

/// A path no generated `write` ever creates.
pub const UNKNOWN_PATH: &str = "nope.bin";

/// One generated step.
///
/// Command ops carry their project so that the same variant serves both the
/// legal form (`PROJECT`) and the illegal one (`UNKNOWN_PROJECT`). `Init` does
/// not: `init nosuch` would *succeed* and give the model a second project to
/// track, which is churn with nothing behind it.
#[derive(Clone, Debug, PartialEq, Eq)]
pub enum Op {
    Write {
        rel_path: &'static str,
        version: u32,
        size: usize,
    },
    Delete {
        rel_path: &'static str,
    },
    Init,
    Scan {
        project: &'static str,
    },
    Status {
        project: &'static str,
    },
    Plan {
        project: &'static str,
        finalize: bool,
        disc_type: Option<&'static str>,
    },
    Burn {
        project: &'static str,
    },
    Verify {
        project: &'static str,
        /// `i64`, not `u32`: an ordinal the domain refuses is interesting, and
        /// keeping the width wide leaves room for it without reaching the
        /// values that fail in the argument parser instead (§3.2).
        disc: Option<i64>,
    },
    History {
        project: &'static str,
        path: &'static str,
    },
    Reset {
        project: &'static str,
    },
    MarkDead {
        project: &'static str,
        ordinal: u32,
    },
}

impl Op {
    /// The project this op names, if any. `None` for tree mutations and `Init`.
    pub fn project(&self) -> Option<&'static str> {
        match self {
            Op::Write { .. } | Op::Delete { .. } | Op::Init => None,
            Op::Scan { project }
            | Op::Status { project }
            | Op::Plan { project, .. }
            | Op::Burn { project }
            | Op::Verify { project, .. }
            | Op::History { project, .. }
            | Op::Reset { project }
            | Op::MarkDead { project, .. } => Some(*project),
        }
    }

/// What the generator believes the project looks like.
///
/// Read from `crates/diskrement-shell/src/pipeline/mod.rs`: `plan` reads the
/// staged scan without consuming it (`mod.rs:196`), `burn` requires a staged
/// scan, a staged plan and `work/snapshot` (`mod.rs:231,263`) and clears all
/// three on success (`mod.rs:330-332`), and `reset` clears the same three
/// (`mod.rs:521`).
#[derive(Clone, Debug, Default)]
pub struct Model {
    pub initialised: bool,
    pub staged_scan: bool,
    pub staged_plan: bool,
    /// `work/snapshot` exists. Created by `scan`, destroyed by `burn` and
    /// `reset`.
    pub snapshot: bool,
    /// Discs the model believes were burned; ordinals are `1..=burned_discs`.
    pub burned_discs: u32,
    pub dead: BTreeSet<u32>,
    /// Files currently in the source tree. **Exact**, see the module doc.
    pub live: BTreeSet<&'static str>,
    /// The highest version ever written for a path, remembered across a delete
    /// so a re-added file gets fresh content rather than repeating v0.
    pub versions: BTreeMap<&'static str, u32>,
    /// Paths the catalog has heard of, so `history` can name a real one.
    pub known_paths: BTreeSet<&'static str>,
}

impl Model {
    /// Ordinals of discs that exist and are not dead.
    fn live_discs(&self) -> Vec<u32> {
        (1..=self.burned_discs)
            .filter(|o| !self.dead.contains(o))
            .collect()
    }

    fn next_version(&self, rel_path: &'static str) -> u32 {
        self.versions.get(rel_path).map_or(0, |v| v + 1)
    }

    /// Ops that should succeed, or at least be refused for a reason the model
    /// does not know about. **Never empty**, and ordered so that index 0 is the
    /// simplest useful op in this state — proptest shrinks the chooser byte
    /// toward zero.
    pub fn legal_ops(&self, payload: u8) -> Vec<Op> {
        let mut ops = Vec::new();
        if !self.initialised {
            ops.push(Op::Init);
        } else {
            ops.push(Op::Scan { project: PROJECT });
            if self.staged_scan {
                ops.push(Op::Plan {
                    project: PROJECT,
                    finalize: false,
                    disc_type: None,
                });
                ops.push(Op::Plan {
                    project: PROJECT,
                    finalize: true,
                    disc_type: None,
                });
                ops.push(Op::Plan {
                    project: PROJECT,
                    finalize: false,
                    disc_type: Some("DVD"),
                });
            }
            if self.staged_plan && self.snapshot {
                ops.push(Op::Burn { project: PROJECT });
            }
            ops.push(Op::Status { project: PROJECT });
            ops.push(Op::Verify {
                project: PROJECT,
                disc: None,
            });
            for ordinal in self.live_discs() {
                ops.push(Op::Verify {
                    project: PROJECT,
                    disc: Some(i64::from(ordinal)),
                });
                ops.push(Op::MarkDead {
                    project: PROJECT,
                    ordinal,
                });
            }
            for path in self.known_paths.iter().copied() {
                ops.push(Op::History {
                    project: PROJECT,
                    path,
                });
            }
            ops.push(Op::Reset { project: PROJECT });
        }
        let size = SIZES[payload as usize % SIZES.len()];
        // `.copied()` throughout: iterating `&[&str]` or `&BTreeSet<&str>`
        // yields `&&'static str`, and the op fields are `&'static str`.
        for rel_path in FILES.iter().copied() {
            ops.push(Op::Write {
                rel_path,
                version: self.next_version(rel_path),
                size,
            });
        }
        for rel_path in self.live.iter().copied() {
            ops.push(Op::Delete { rel_path });
        }
        ops
    }

    /// Ops the model expects to be refused. **Never empty.**
    ///
    /// These are as valuable as the legal ones: the oracle is agreement, not
    /// success, and error wording plus the exit-code ladder are both contract
    /// (CLAUDE.md: 2 = state/lookup, 3 = environment/oversize). No entry here
    /// fails in the argument parser — see the module doc.
    ///
    /// Takes no payload: an illegal op has nothing to size.
    pub fn illegal_ops(&self) -> Vec<Op> {
        let mut ops = vec![
            Op::Status {
                project: UNKNOWN_PROJECT,
            },
            Op::Plan {
                project: UNKNOWN_PROJECT,
                finalize: false,
                disc_type: None,
            },
            Op::Burn {
                project: UNKNOWN_PROJECT,
            },
            Op::Reset {
                project: UNKNOWN_PROJECT,
            },
            Op::Verify {
                project: UNKNOWN_PROJECT,
                disc: None,
            },
            Op::History {
                project: UNKNOWN_PROJECT,
                path: UNKNOWN_PATH,
            },
            Op::MarkDead {
                project: UNKNOWN_PROJECT,
                ordinal: 1,
            },
        ];
        if self.initialised {
            // A second `init` on a project that exists.
            ops.push(Op::Init);
            // A path the catalog never heard of: exit 0 with a "no history"
            // sentence, which is still a full stdout comparison.
            ops.push(Op::History {
                project: PROJECT,
                path: UNKNOWN_PATH,
            });
            // Ordinals no disc has. `+ 9` rather than `+ 1` so that a burn the
            // model failed to predict cannot make these accidentally valid.
            ops.push(Op::Verify {
                project: PROJECT,
                disc: Some(i64::from(self.burned_discs) + 9),
            });
            ops.push(Op::MarkDead {
                project: PROJECT,
                ordinal: self.burned_discs + 9,
            });
            if !self.staged_scan {
                ops.push(Op::Plan {
                    project: PROJECT,
                    finalize: false,
                    disc_type: None,
                });
            }
            if !self.staged_plan {
                ops.push(Op::Burn { project: PROJECT });
            }
            for ordinal in self.dead.iter().copied() {
                // Naming a dead disc is an error; a sweep skips it silently.
                ops.push(Op::Verify {
                    project: PROJECT,
                    disc: Some(i64::from(ordinal)),
                });
                // Marking one dead twice is refused, and must append no second
                // event — which the state diff checks, not just the exit code.
                ops.push(Op::MarkDead {
                    project: PROJECT,
                    ordinal,
                });
            }
        }
        ops
    }

    /// Turn one generated triple into an op against the current state.
    ///
    /// `selector % 5 == 4` is the illegal fifth. The comparison is against 4
    /// rather than 0 deliberately: proptest shrinks bytes toward zero, and a
    /// shrunk sequence should be a *legal* one.
    pub fn interpret(&self, selector: u8, chooser: u8, payload: u8) -> Op {
        let ops = if selector % 5 == 4 {
            self.illegal_ops()
        } else {
            self.legal_ops(payload)
        };
        debug_assert!(!ops.is_empty(), "no op is available in state {self:?}");
        ops[chooser as usize % ops.len()].clone()
    }

    /// Advance the model past `op`.
    ///
    /// Only ops aimed at the real project can move it: one aimed at
    /// `UNKNOWN_PROJECT` fails at the project lookup before touching anything.
    /// Every guess here may be wrong without consequence except the `live` set
    /// — see the module doc.
    pub fn apply(&mut self, op: &Op) {
        match op {
            Op::Write {
                rel_path, version, ..
            } => {
                self.versions.insert(*rel_path, *version);
                self.live.insert(*rel_path);
            }
            Op::Delete { rel_path } => {
                self.live.remove(*rel_path);
            }
            Op::Init => self.initialised = true,
            Op::Scan { project } if *project == PROJECT => {
                self.staged_scan = true;
                self.snapshot = true;
            }
            Op::Plan { project, .. } if *project == PROJECT && self.staged_scan => {
                // `plan` does not consume the staged scan (`mod.rs:196`), so
                // re-planning stays legal and idempotent.
                self.staged_plan = true;
            }
            Op::Burn { project }
                if *project == PROJECT && self.staged_plan && self.snapshot =>
            {
                self.burned_discs += 1;
                self.staged_scan = false;
                self.staged_plan = false;
                self.snapshot = false;
                let live: Vec<&'static str> = self.live.iter().copied().collect();
                self.known_paths.extend(live);
            }
            Op::Reset { project } if *project == PROJECT => {
                self.staged_scan = false;
                self.staged_plan = false;
                self.snapshot = false;
            }
            Op::MarkDead { project, ordinal }
                if *project == PROJECT && *ordinal <= self.burned_discs =>
            {
                self.dead.insert(*ordinal);
            }
            _ => {}
        }
    }
}
```

```rust
/// One generated case: a disc capacity and a list of opaque choices.
///
/// The choices are `(selector, chooser, payload)` triples that `Model`
/// interprets in order (spec §8.1, decision 2). Interpretation happens on
/// demand rather than being stored, so a shrunk `Sweep` is re-interpreted
/// against the state its shorter prefix produces — which is what makes plain
/// `Vec`/`u8` shrinking sound here.
#[derive(Clone, PartialEq, Eq)]
pub struct Sweep {
    disc_bytes: Option<u64>,
    choices: Vec<(u8, u8, u8)>,
}

impl Sweep {
    pub fn new(disc_bytes: Option<u64>, choices: Vec<(u8, u8, u8)>) -> Self {
        Sweep {
            disc_bytes,
            choices,
        }
    }

    /// Interpret the choices against a model threaded through them.
    pub fn ops(&self) -> Vec<Op> {
        let mut model = Model::default();
        let mut ops = Vec::with_capacity(self.choices.len());
        for (selector, chooser, payload) in &self.choices {
            let op = model.interpret(*selector, *chooser, *payload);
            model.apply(&op);
            ops.push(op);
        }
        ops
    }

    /// Lower to an ordinary scenario, so the sweep and the corpus share one
    /// runner and one step vocabulary.
    pub fn to_scenario(&self) -> Scenario {
        Scenario {
            name: "sweep".to_string(),
            disc_bytes: self.disc_bytes,
            steps: self.ops().iter().map(Op::to_step).collect(),
        }
    }

    /// The sequence as `corpus.rs` source.
    ///
    /// This is the failure report: proptest prints `Debug` of the shrunk input,
    /// so promoting a counterexample to a named scenario is a copy.
    pub fn to_source(&self) -> String {
        let mut out = String::new();
        out.push_str("// generated by the P9 sweep — name it and paste it into corpus.rs\n");
        out.push_str("Scenario {\n");
        out.push_str("    name: \"NAME-ME\".into(),\n");
        out.push_str(&format!("    disc_bytes: {:?},\n", self.disc_bytes));
        out.push_str("    steps: vec![\n");
        for op in self.ops() {
            out.push_str(&format!("        {}\n", op.to_source()));
        }
        out.push_str("    ],\n}\n");
        out
    }
}

impl std::fmt::Debug for Sweep {
    /// Deliberately not derived: proptest prints this on failure, and the
    /// opaque `(u8, u8, u8)` triples would tell a reader nothing.
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        f.write_str(&self.to_source())
    }
}
```

```rust
/// One scratch tree running the sequence under one mode.
///
/// Each world carries **its own `Normalizer`**: the three live in three
/// different scratch roots, and instant ordinals are assigned in
/// first-appearance order. All three are advanced at the same points, in the
/// same order, so their numbering corresponds.
struct World<'a> {
    session: Session<'a>,
    norm: Normalizer,
    /// The most recent command outcome. `None` before the first command.
    last: Option<StepSnapshot>,
}

impl<'a> World<'a> {
    fn open(bins: &'a Binaries, disc_bytes: Option<u64>, mode: Mode) -> Result<Self, Skip> {
        let session = Session::open(bins, mode, disc_bytes)?;
        let norm = Normalizer::new(&session.scratch().root);
        Ok(World {
            session,
            norm,
            last: None,
        })
    }

    fn mode(&self) -> Mode {
        self.session.mode()
    }

    fn apply(&mut self, step: &Step) -> Result<(), Skip> {
        // The session owns the mode and derives the binary itself, so the
        // read-before-increment ordering is not this caller's to get wrong.
        let outcome = self.session.apply(step)?;
        let snapshot = outcome.map(|o| state_diff::step_snapshot(&o, &mut self.norm));
        self.last = snapshot;
        Ok(())
    }

    /// Capture what is on disk. Safe here and only here: no child is running
    /// between two command invocations, so the SQLite `-wal` has been
    /// checkpointed away and `immutable=1` sees everything.
    fn state(&mut self) -> StateSnapshot {
        state_diff::state_snapshot(self.session.scratch(), &mut self.norm)
    }
}

/// Run one generated sequence through all three modes, diffing after every
/// command. `Err` carries the report for the first divergence.
///
/// A `Skip` from inside here is a panic, not a skip: the environment was probed
/// before the sweep started, so a failure at this point is a harness defect.
fn compare(bins: &Binaries, sweep: &Sweep) -> Result<(), String> {
    let scenario = sweep.to_scenario();
    // Three explicit bindings rather than a closure: `World` borrows `bins`,
    // and a closure returning a value with an inferred lifetime is the kind of
    // thing that compiles only after an argument with the borrow checker.
    let mut reference = World::open(bins, scenario.disc_bytes, Mode::Scala)
        .unwrap_or_else(|Skip(r)| panic!("could not open the all-scala world: {r}"));
    let mut rust = World::open(bins, scenario.disc_bytes, Mode::Rust)
        .unwrap_or_else(|Skip(r)| panic!("could not open the all-rust world: {r}"));
    let mut interleaved = World::open(bins, scenario.disc_bytes, Mode::Interleaved)
        .unwrap_or_else(|Skip(r)| panic!("could not open the interleaved world: {r}"));

    for (i, step) in scenario.steps.iter().enumerate() {
        for world in [&mut reference, &mut rust, &mut interleaved] {
            world
                .apply(step)
                .unwrap_or_else(|Skip(reason)| panic!("step {i} could not be applied: {reason}"));
        }
        if !matches!(step, Step::Cmd { .. }) {
            continue;
        }
        let reference_step = reference
            .last
            .clone()
            .expect("a command step always produces an outcome");
        let reference_state = reference.state();
        for candidate in [&mut rust, &mut interleaved] {
            let candidate_step = candidate
                .last
                .clone()
                .expect("a command step always produces an outcome");
            let mut diffs = Vec::new();
            state_diff::step_differences(i, &reference_step, &candidate_step, &mut diffs);
            let candidate_state = candidate.state();
            state_diff::state_differences(&reference_state, &candidate_state, &mut diffs);
            if !diffs.is_empty() {
                return Err(format!(
                    "step {i} ({}) diverges: all-scala is (a), {} is (b)\n\n{}",
                    reference_step.label,
                    candidate.mode().label(),
                    diffs.join("\n\n")
                ));
            }
        }
    }
    Ok(())
}

/// Run the sequence twice through the Scala binary alone and diff the two.
///
/// Only called on failure, and it is the difference between a night spent on a
/// porting bug and a night spent on an unnormalized timestamp: if all-Scala
/// does not reproduce itself, the divergence just reported says nothing about
/// the Rust port. This is the corpus bootstrap's guarantee, applied to a
/// sequence the corpus never saw.
fn scala_reproduces_itself(bins: &Binaries, sweep: &Sweep) -> Result<(), String> {
    let scenario = sweep.to_scenario();
    let once = |label: &str| -> Result<state_diff::Snapshot, String> {
        let run = runner::run(bins, &scenario, Mode::Scala)
            .map_err(|Skip(reason)| format!("the {label} reference run skipped: {reason}"))?;
        let mut norm = Normalizer::new(&run.scratch.root);
        Ok(state_diff::snapshot(&run, &mut norm))
    };
    let first = once("first")?;
    let second = once("second")?;
    let diffs = state_diff::differences(&first, &second);
    if diffs.is_empty() {
        Ok(())
    } else {
        Err(diffs.join("\n\n"))
    }
}
```

- [ ] **Step 2: Triage the counterexample**

The sweep stops at the first failure, so this is a loop: one counterexample at a
time, fixed and committed, then run wide again. For each one, in order:

1. **Read the verdict line.** If it says the all-Scala run does not reproduce
   itself, this is a **harness defect**: some value varies between two runs of
   the same binary and is not normalized. Fix it in `normalize.rs` — a *named*
   rule with a doc comment saying what varies and why erasing it is safe, plus a
   unit test — or in `runner.rs`, by making the environment deterministic the
   way `pin_mtime` already does. Never widen an existing rule to swallow it.
   Prefer determinism to normalization: a rule is a hole in the oracle, a pinned
   environment is not.
2. **Otherwise read the diverging step.** The report names it and shows both
   sides. Reproduce it by hand before changing anything:

```bash
# paste the printed Scenario into corpus.rs under a temporary name, add it to
# corpus::all(), then:
cargo test -p diskrement-difftest --test differential -- --ignored --nocapture
```

3. **Classify it:**
   - *A porting bug in the Rust tree.* The common case. Fix it under TDD — the
     failing differential run is the red; add the narrowest unit test in the
     crate that owns the behaviour, make it pass, then confirm the sweep agrees.
   - *A divergence the spec sanctions.* Only §3.2's argument-parser wording
     qualifies, and the generator is built not to reach it (D6). If one appears
     anyway, the generator has a bug: fix `sequence.rs` so it stops emitting
     that shape, rather than exempting the step.
   - *Scala is arguably wrong and Rust is arguably right.* **Rust still matches
     Scala.** Compatibility is the contract (§3.1); an improvement is a change
     to make after the swap, not during it. Record it in *Execution deviations*
     as a candidate for post-P10 work.
4. **Promote it.** Give the scenario a real name and a doc comment saying what
   it caught, add it to `corpus::all()`, and keep it — it is now a cheap,
   JVM-free-until-run regression test that outlives the sweep's seed.
5. **Commit the fix and the scenario together**, so the scenario is never
   committed red:

```bash
git add crates/diskrement-shell/src crates/diskrement-difftest/src/corpus.rs
git commit -m "fix(<area>): <what diverged, in the user's terms>

Found by the P9 sweep. <One sentence on the mechanism.> The shrunk
sequence is promoted to corpus::<name> so it stays checked after the
harness is deleted at P10."
```

6. **Re-run wide from the top.** A fix can unmask the next divergence, and the
   seed sequence changes anyway.

  scenario writes, because `content()` is keyed on `"{rel_path}@{version}"`.
  Two `matches!` assertions now pin that. A comment was also added saying the
  `format!`s in the sibling test *are* the assertion, so a later tidying pass
